## 建模的基础

一个三维场景由三样东西构成:**模型、灯光、摄像机**。

建模的基本工作流:**建模 → 布光 → 材质 → 渲染**。先把事情结构化,再一步步解决(也就是"第一性原理"思维)。

## 视图控制

Blender 中操作视图是最基础的技能:

| 操作 | 快捷键 |
|---|---|
| 旋转视角 | 鼠标**右键**拖动 |
| 平移视角 | `Shift` + 鼠标滚轮(中键) |
| 缩放视图 | 鼠标滚轮 |
| 正视图 / 侧视图 / 顶视图 | 小键盘 `1` / `3` / `7` |
| 反转视图 | 小键盘 `9` |
| 正交/透视切换 | 小键盘 `5` |
| 摄像机视图 | 小键盘 `0` |
| 观察选中物体 | 小键盘 `.` |
| 视图切换菜单(Pie 菜单) | 按住 `~` |
| 游标回到原点 | `Shift + C` |

除了快捷键,也可以使用界面**右上角的视角导航手柄**:

## 核心概念:游标、原点、坐标

### 游标

![游标](https://pub-070cddfab8c44f3c8aa1cd0988fd4a3c.r2.dev/2026-8-30-Blender学习笔记/02-游标.png)

游标有两个主要作用:

1. **新建的物体出现在游标的位置**
2. 作为物体**旋转的轴心点**

移动游标:`Shift + 右键`;游标回到原点:`Shift + C`。

### 原点

每个物体都有一个**原点**(物体上的黄色小点),它记录了物体的位置信息,也会影响缩放的中心。缩放时如果不是以预期位置缩放,可以检查一下原点位置。

### 全局坐标与局部坐标

- **全局坐标**:以世界原点为中心
- **局部坐标**:以物体原点为中心

在移动/缩放/旋转时,**连续按两下 `X`/`Y`/`Z`** 可以在全局坐标和局部坐标之间切换。

## 渲染引擎:EEVEE vs Cycles

| 渲染引擎 | 优点 | 缺点 |
|---|---|---|
| **EEVEE** | 快,相对不占资源 | 没有光线追踪,光线阴影细节不佳,需要更多参数辅助 |
| **Cycles** | 逼真,能模拟物理世界里非常细节的光线阴影 | 慢,相对更消耗硬件资源 |

新手建议先用 EEVEE 快速预览,出正式图再换 Cycles。

另外:**灯光的半径越大,光线越柔和**。

## 摄像机与输出设置

调整摄像机位置的步骤:

1. 再调出一个 3D 视图窗口(面板可以拆分/替换)
2. 按小键盘 `0` 切换到摄像机视角
3. 按 `N` 调出右侧面板 → 视图 → 锁定视图 → 勾选**摄像机到视图方位**
4. 这时拖动视角就是在移动摄像机,可以自由构图

![摄像机锁定视图](https://pub-070cddfab8c44f3c8aa1cd0988fd4a3c.r2.dev/2026-8-30-Blender学习笔记/09-摄像机锁定视图.png)

可以将**遮光框调到 100%**,更真实地观察输出画面;在**输出属性**中可以调整摄像机输出画面的尺寸:

![输出尺寸设置](https://pub-070cddfab8c44f3c8aa1cd0988fd4a3c.r2.dev/2026-8-30-Blender学习笔记/10-输出尺寸设置.png)

## 四种视图预览方式

视口右上角可以切换四种预览模式,从左到右依次为:**线框、实体、材质预览、渲染**:

![四种视图预览](https://pub-070cddfab8c44f3c8aa1cd0988fd4a3c.r2.dev/2026-8-30-Blender学习笔记/11-四种视图预览.png)

- **线框**:只看结构,运行最流畅
- **实体**:默认工作模式
- **材质预览**:快速预览材质效果
- **渲染**:真实渲染效果,最慢
