因为PCL启动器并没有mac端，所以我在mac端一直使用的是HMCL启动器。最初我就是把HMCL放在Applications文件夹中，每次想玩的时候要通过访达去点击.jar文件来打开启动器，十分麻烦。所以我决定将其封装成一个APP的格式。

## **封装过程**

KIMI给我推荐了不少第一方或是第三方的jar包封装工具，但是都比较麻烦。但是在kimi的网页搜索中有查到一篇<a href="https://blog.csdn.net/HYZ1206/article/details/151148160" target="_blank">手动封装的帖子</a>，索性就照着他做了下来，成功运行。所以大家可以直接查看该帖子。本帖只是复述该帖子。

### **步骤零 下载HMCL启动器**

> 下载好的小伙伴也别略过这一章！这事关你的游戏和存档。
{: .prompt-danger }

没有下载的小伙伴直接前往<a href="https://hmcl.huangyuhui.net/" target="_blank">HMCL官网</a>下载即可，记住文件保存的位置备用。

#### ***游戏数据保存***

当然，我相信能看到本教程的绝大部分都是已经凑合使用过一段时间的人。那么，你已经下载游玩的游戏版本和存档也需要移植到新的地方。
首先，进入你存放`HMCL.jar`的地址。例如，我将jar包存放在`/Users/<你的mac用户名>/Project/Minecraft`中，在当前文件夹界面输入快捷键`Command+Shift+.`显示隐藏文件，你会看到`.minecraft`和`.hmcl`两个隐藏文件夹，其中的`.minecraft`文件夹中存放的就是你下载的所有mc版本和游戏存档。另一个存放着你对HMCL启动器本身的相关设置数据。

![隐藏文件夹](/assets/img/post-img/2026-1-11-在mac端为将.jar应用制作.app应用（保姆级教程）/隐藏文件夹.png)
_隐藏的文件夹_
删除两个文件夹前面的`.`，因为`.`在linux，unix（mac是类unix系统）等操作系统中，用于隐藏文件，删除`.`即可使文件夹正常显示。如果当前目录你可以轻易找到且较为干净，可以继续将两个文件夹放在当前文件夹备用。否则，建议复制存放到一个易于查找的位置，如桌面。

### **步骤一 建立目录**

macos的app可以看作是一个可以打开的文件夹，所以我们需要创建一个.app目录，目录格式如下所示：
<span id="cmd"></span>
```
项目结构：
HMCL.app
└── Contents
    ├── MacOS
    └── Resources
```

不管是直接在finder中创建还是通过命令行创建，都可以。  
#### finder（访达）
如果使用finder图形化界面创建结构，在你的文件夹中新建文件夹，并重命名为`HMCL.app`，这时候会有弹窗提示，点击添加即可。这时，文件夹会变成一个空白图标的软件，右键，选择`显示包内容`即可进入文件夹，继续按照上面的结构创建子文件夹。

> 吐槽：mac的finer是真的难用，不能新建文件，也不能在当前文件夹打开终端。

#### 控制台指令
或者，通过更便捷的控制台指令进行操作。若是对以下指令有疑问，可以查看<a href="https://www.runoob.com/w3cnote/linux-common-command-2.html" target="_blank">linux常用命令手册</a>，macos中控制台指令和linux绝大部分是一样的。  
`command+空格` 打开聚焦搜索，搜索`终端`或是`terminal`，打开终端，进入一个你能很快找到的文件夹位置，例如`文稿`。使用<a href="https://www.runoob.com/linux/linux-comm-cd.html" target="_blank">`cd`</a>指令进入你的目标文件夹：
```shell
cd ~/Documents
```
看到终端中的前缀类似`XXX@XXXMacBook-Pro Documents % `即可。  
接着创建项目结构。<a href="https://www.runoob.com/linux/linux-comm-mkdir.html" target="_blank">`mkdir`</a>是创建文件夹的指令。`-p`告诉`mkdir`如果路径里某一级目录已经存在，就别报错；缺几级就自动帮我补几级。
```shell
mkdir -p HMCL.app/Contents/{MacOS,Resources}
```
完成后打开finder，进入对应文件夹，你会找到一个图标是空白的，名称为HMCL的应用。右键应用，点击显示包内容，查看该应用的结构，如果[结构正确](#cmd)，则创建成功。  
### **步骤二 把jar放进Resources**
把自己的`HMCL-x.x.x.jar`文件放入Resources文件夹中。  
### **步骤三 创建启动脚本**
在`HMCL.app/Contents/Resources`中创建一个文件`launch.sh`。由finder中不能直接创建文件（真的很无语😓），我的做法是使用终端进行创建，打开终端，使用`cd`命令进入到`Resources`文件夹下，使用<a href="https://www.runoob.com/linux/linux-comm-touch.html" target="_blank">`touch`</a>命令创建文件。用文本编辑器打开该文件，输入以下内容：
```shell
#!/bin/bash
# 获取 APP 路径
APP_DIR="$(cd "$(dirname "$0")"; pwd)"

# 切换到用户目录，避免权限问题
cd "$HOME"

# 启动 HMCL（版本号输入自己所用的版本号）
exec /usr/bin/java -jar "$APP_DIR/../Resources/HMCL-x.x.x.jar" --dataDir "$HOME/Library/Application Support/HMCL"

```
保存后，使用终端进入到`MacOS`目录下，输入以下命令给予脚本权限：
```shell
chmod +x HMCL.app/Contents/MacOS/launch.sh
```
### **步骤四 创建应用配置文件**
在`HMCL.app/Contents`下创建文件`Info.plist`，输入内容：
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <!-- 应用名称 -->
    <key>CFBundleName</key>
    <string>HMCL</string>

    <!-- 启动的可执行文件 -->
    <key>CFBundleExecutable</key>
    <string>launch.sh</string>

    <!-- 唯一标识符 -->
    <key>CFBundleIdentifier</key>
    <string>com.example.HMCL</string>

    <!-- 版本号（填写自己所用的HMCL版本） -->
    <key>CFBundleVersion</key>
    <string>x.x.x</string>
    <key>CFBundleShortVersionString</key>
    <string>x.x</string>

    <!-- 应用类型 -->
    <key>CFBundlePackageType</key>
    <string>APPL</string>

    <!-- 应用图标（可选，放在 Resources/Minecraft.icns注意修改图标命名） -->
    <key>CFBundleIconFile</key>
    <string>HMCL</string>
</dict>
</plist>
```
### **步骤五 配置应用图标**
<a href="/assets/img/post-img/2026-1-11-在mac端为将.jar应用制作.app应用（保姆级教程）/HMCL.icns" target="_blank">点击此处下载图标</a>，将图标存放在`Resources`目录下。
> **注意：**这里的文件名称要和`Info.plist`中`CFBundleIconFile`下的文件名一致（无需理会后缀）。这里需要使用Chrome浏览器点击才能下载，Safari浏览器需要右键超链接，选择`下载链接文件`下载文件。
{: .prompt-info }

### **步骤六 测试是否成功运行**
点击制作完成的应用，查看是否能正常运行。如果正常运行，那就可以开始转移数据了。如果打开失败了，请自己问问AI吧（或者发邮件问我）。

### **步骤七 转移数据**
HMCL的配置文件路径在`~/Library/Application Support/HMCL`，Minecraft的默认存储位置在`~/Library/Application Support/minecraft`。Finder默认隐藏`~/Library`，先用先前使用的方法显示隐藏文件，再加入相关路径，将自己的数据存放到新的路径下。我没有试过直接覆盖原文件夹，你可以进行尝试。如果失败了，还是自己慢慢迁移比较好。记得先倒入HMCL配置文件，再倒入MC数据。这样保险些。
> 如果没有这些文件夹，可以先打开HMCL，下载一个mc版本，这样HMCL会自动创建相关目录，此时就能找到相关文件夹了。

至此，你就成功地将.jar文件的应用转换成了.app的MacOS应用了，往后有类似的.jar应用也可以照此方法app化。（应该吧，其实我也没有尝试过）
