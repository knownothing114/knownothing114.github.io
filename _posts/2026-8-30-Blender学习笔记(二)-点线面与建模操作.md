接上一篇笔记,这篇记录建模的核心内容:**编辑模式、点线面操作与十大建模操作**。

## 编辑模式

选中物体后按 `Tab` 进入**编辑模式**,可以改变、移动物体的**点、线、面**:

- 点 / 线 / 面选择模式切换:快捷键 `1` / `2` / `3`
- 选择模式(框选/刷选等)切换:快捷键 `W`

进入编辑模式后,选中点线面,操作和物体模式一样:`G` 移动、`R` 旋转、`S` 缩放、`X` 删除。

## 点线面的选择技巧

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 反选 | `Ctrl + I` | 选中当前未选中的元素 |
| 选择相连元素 | `L` | 鼠标放在元素上,选中与该元素相连的所有元素 |
| 循环选择 | `Option` + 双击左键 | 选中与当前点相连的一圈点/边 |
| 随机选择 | 选择菜单中开启 | 随机选中部分元素 |
| 增加/减少选区 | `Ctrl` + 小键盘 `+` / `-` | 按范围扩展/收缩选区(必须是小键盘) |
| 透视模式 | `Option + Z` | 透过物体选中背面的点(透视模式下框选) |

小技巧:想选中物体**背面**的点,先开启透视模式(`Option + Z`)再框选即可。

## 点线面的控制

### 融并

删除点线面后,把剩下的边"缝起来"的操作叫做**融并**,避免删除后留下破洞。

### 法线

法线用来区分物体的正反面:

- 打开**面朝向**显示:**蓝色是正面,红色是反面**
- 建模时要注意法线方向,反面会影响后续的材质和渲染效果

## 十大建模操作

> 以下操作都在**编辑模式**下进行。

### 四大操作

| 操作 | 快捷键 | 说明 |
|---|---|---|
| **挤出** | `E` | 挤出并移动;`Ctrl + 右键` 连续快速挤出 |
| **内插** | `I` | 向内挤出(内部插入面) |
| **倒角** | `Ctrl + B` | 选中一条边添加倒角;滚动鼠标滚轮可增加细分面 |
| **循环切割** | `Ctrl + R` | 在物体上添加一圈循环线 |

> **注意:** 挤出的取消要注意:按右键只取消移动,新增加的面还在,需要 `Ctrl + Z` 才能真正撤销。
{: .prompt-warning }
### 六小操作

| 操作 | 快捷键 | 说明 |
|---|---|---|
| **合并** | `M` | 合并选中的点/物体 |
| **断开** | `V` | 将顶点断开(撕开) |
| **填充** | `F` | 用面填充空隙;多点填充可用 `Ctrl + F` 菜单里的栅格填充(注意:栅格填充要求偶数个点) |
| **切刀** | `K` | 手动切割;切完后按**空格键**退出 |
| **桥接** | `Ctrl + E` → 桥接循环边 | 需要先把两个物体合并(`Ctrl + J`),再选中两条需要桥接的边 |
| **分离** | `P` | 把选中的部分分离成独立物体 |

## 常用修改器

修改器位于右侧属性面板,是**非破坏性**的建模工具:

| 修改器 | 位置 | 作用 |
|---|---|---|
| **表面细分** | 修改器 → 生成 → 表面细分 | 让模型表面更平滑细腻 |
| **实体化** | 修改器 → 生成 → 实体化 | 给平面/网格增加厚度 |
| **倒角** | 修改器 → 生成 → 倒角 | 给物体边缘增加倒角 |
| **布尔** | 修改器 → 生成 → 布尔 | 对两个物体做交集、差集、并集运算(偶尔会出现奇怪的问题,慎用) |

## 建模小技巧

1. **缩放时机**:尽量不要在物体模式下缩放物体,尽量在编辑模式下缩放;如果已经在物体模式下缩放过了,记得"应用缩放"(`Ctrl + A` → 应用 → 缩放),否则会影响后续的倒角、修改器等操作。

2. **表面细分快捷键**:`Ctrl + 2` 可以快速给选中物体添加表面细分修改器(2 级细分)。

3. **父子级关系**:先选中**儿子**,再选中**爸爸**,按 `Ctrl + P` → 物体,设置父子级。之后移动爸爸,儿子会跟着移动;移动儿子,爸爸不会动。适合做组装类模型(比如蘑菇的斑点)。

4. **面吸附**:做表面贴附(如给蘑菇面加斑点)时,开启吸附工具,并可能需要把被吸附物体的**原点移到几何中心**(右键物体 → 设置原点 → 原点 → 几何中心),吸附才会准确。
